# Chris’s Cosmology Course — pedagogical pack

This directory is a **pedagogy pack** for deep understanding of the **cosmological principle (CP)**: what it asserts, what it does not, how it enters the **Friedmann–Lemaître–Robertson–Walker (FLRW)** metric, and what would pressure or falsify it. The **Center-of-Expansion (CoE) / off-center project** (spherical decreasing-density expansion; observer at \(D\); vision shell \(r\); \(R_{\mathrm{CMB}}\gg D\); Gauss/shell; **cosmic microwave background (CMB)** dipole budget; Migkas/Secrest as claims-with-caveats; Alnes–Kodama; **kinematic Sunyaev–Zeldovich (kSZ)**) is the **spine through every module**, not a finale bolt-on. Broader cosmology is taught in service of CP understanding; the CoE sketch is the continuous clarifying case — same evidentiary standard as **ΛCDM** (Lambda cold dark matter), advocacy neither way. Tone: plain speech, physical intuition first, chemistry and applied-physics analogies, peer-reviewed and textbook sources already verified in-pack, tensions flagged honestly. Amp\(\times\sin\) / \(2\ell\) / \(R^2\) to digitised Migkas are diagnostics, not proofs. **All acronyms are defined before common use** in each file (see Module 1 glossary as the template).

**File map.** `00-learning-objectives.md` — outcomes (CP via CoE spine; Module 9 final paper). `01-course-outline.md` — nine modules with woven project-thread exercises. `modules/01-cosmological-principle.md` … `modules/08-averaging-backreaction.md` — module drafts. `modules/09-spine-review-final-paper.md` — spine checklist + final paper (replaces old standalone capstone `09-falsifiable-coe-test.md`). Shared figures and research notes live under `/workspace/cosmology/` (linked from modules); they are not copied here so both agents share one source of truth.
