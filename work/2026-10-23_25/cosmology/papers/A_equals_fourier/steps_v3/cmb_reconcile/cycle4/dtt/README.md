# ΔT/T vs angle on the CMB emission sphere (cycle4 compact core + shell)

1. Setup: Chris compact core (point) + Ω_s = 0.049 shell (R_in = D − 1.028 R, R_out = D + 1.475 R), R = 14.3 Gpc. Gravity only, Λ = 0. Newtonian, today's field. ⟨H⟩ = 71.6. Mc re-solved per D so cluster quadrupole a2 = 0.084 at Rs = 0.31 Gpc. Mc/Mcrit ≈ 0.0019 (headline). Angle θ = 0 toward CoE, 180 away. Same linear Doppler convention as cycle4: ΔT/T_Doppler = −n·(V_emit − V_obs)/c; static = (Φ_emit − Φ_obs)/c².
2. D = 14.7 Gpc (shell minimum): Doppler peak-to-peak = 0.616; Doppler a2 = −0.0387; static a2 = −0.0110; total a2 = −0.0496. Mc/Mcrit = 0.00187. Fractional (linear/(HR/c)) a2 = −0.0113. Note: vrmin < 0 — matter near θ ≲ 25° has turned around; curve oscillates there.
3. D = 22.28 Gpc (exact static cancel from cycle4, D_null = 22.276): Doppler peak-to-peak = 3.032; Doppler a2 = −0.411; static a2 ≈ 0 (−4.7e−10; core mass = cavity mass, M_eff ≈ 0). Mc/Mcrit = 0.00193. Fractional a2 = −0.120. Note: turnaround spike near θ ≈ 10° inflates peak-to-peak; quadrupole is the robust metric.
4. D = 49 Gpc (headline): Doppler peak-to-peak = 0.795; Doppler a2 = −0.385; static a2 = +0.0867; total a2 = −0.298. Mc/Mcrit = 0.00196. Fractional a2 = −0.113. No turnaround (vrmin > 0).
5. Target residual: the kinematic Doppler term from emitter motion. It is O(0.04–0.4) in a2 at every preferred D — 4,000× to 40,000× over the CMB quadrupole limit ~1e−5. Static can be nulled at D = 22.28; Doppler cannot.
6. Caveat HR/c ≈ 3.42: linear v/c is outside its range. Fractional anisotropic-expansion estimate = (linear Doppler)/(HR/c) gives |a2| ≈ 0.011–0.12 (peak-to-peak ≈ 0.18–0.89) — still ≫ 1e−5; does not change the verdict.
7. Files: compute_dtt.py → dtt.json; plot_dtt.py → dtt_vs_theta.png, dtt_doppler_linear_vs_frac.png. Reuses ../lib4.py.

## Photon energy correction plot
- `kill_energy_pct_0_360.png` plots `100 * kill`, where `kill = -(dtt_doppler - mean(dtt_doppler))`, over the axisymmetric phi = 0-360 deg great circle. Positive dE/E is photon energy gain; negative is energy loss.
- The thick red curve is the required correction. The green band/lines mark the observed anisotropy limit `|Delta T/T| = 1e-5 = +/-0.001%`. The y-axis is symmetric-log so this narrow limit remains visible against the large required corrections.
