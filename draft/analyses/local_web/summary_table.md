# Random local-web ('foam') layouts around the visible sphere

Start: 237.3× the 1e-5 floor. Four fitted clumps (compensated): 88.8×. Region: 14.3–30 Gpc from us, CoE interior excluded (volume 88,199 Gpc³).

Packing used (shares of each cell's own mass and volume): voids 78% vol / 23% mass (δ = −0.70); walls 6% / 8%; filaments 15.5% / 40%; clusters (web junctions) 0.5% / 28.6%. Every cell is exactly mass-compensated, so net mass is zero.
