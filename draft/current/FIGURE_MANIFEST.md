# Figure manifest — *CoE collected papers* packet (115 pages, Figs. 1–114)

Packet: [`papers/collected/CoE_collected_papers.pdf`](papers/collected/CoE_collected_papers.pdf) · sources and build scripts: [`papers/collected/`](papers/collected/)

For every figure: the image file used in the TeX source, the script that generates it, the input data it reads, and the **plotted data points** exported at the moment the figure was saved (compressed `.npz`, one array per plotted line / scatter / image, keys `ax<i>_line<j>_x/_y`, `ax<i>_coll<j>_xy`, `ax<i>_img<j>`, `ax<i>_bars`).

Scripts and inputs were identified by **running every generating script under a file-access tracer** (all files opened for reading were recorded), not by guessing. Every script was rerun on Oct 13, 2026; the "regen" result in the status column compares the rerun output with the image in the packet.

**Status key:** **a** = code and data were already in the repo · **b** = present on the working machine but not in the repo; added in this commit · **c** = third-party image (citation given) · **d** = hand-made/schematic, no generating code · **e** = ⚠ generating code **not found**.

**Counts:** a = 20, b = 54, c = 29, d = 2, e = 9 (total 114).

**Renumbering (Oct 13):** old Fig. 31 (harmonics sheet) deleted as a duplicate of Fig. 35 (old Fig. 37); old Fig. 32 (NCP hemisphere) moved to the last page as Fig. 114; old Figs. 33–115 are now Figs. 31–113 (pages after 34 shift by −1). Later the same day the Acknowledgments page (p. 34) was removed at the author's request; pages from 34 on shift by a further −1. Page numbers in this table are read from the packet PDF.

**Figures with no code found (e):** Fig. 3, Fig. 11, Fig. 12, Fig. 20, Fig. 21, Fig. 23, Fig. 24, Fig. 26, Fig. 30.
**Partial reproductions** (code found, but a manual crop/stack step or a lost input, or the current script draws a later version): Fig. 1, Fig. 2, Fig. 4, Fig. 8, Fig. 10, Fig. 25, Fig. 29, Fig. 58.

## How to rerun

```bash
python3 draft/current/figure_sources/rebuild_layout.py /tmp/coe_root   # recreates the original /workspace layout from the repo
cd /tmp/coe_root/workspace/<script dir> && python3 <script>.py
```
[`figure_sources/PATHMAP.json`](figure_sources/PATHMAP.json) maps each original path to its place in this repo. Files that were already in the repo are referenced where they are; new files are under [`figure_sources/src/`](figure_sources/src/) mirroring the original layout. Plotted points: [`figure_sources/plotdata/`](figure_sources/plotdata/).
